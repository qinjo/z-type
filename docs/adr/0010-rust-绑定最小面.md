# ADR-0010 Rust 绑定用 librime-sys，仅在安全封装层暴露最小 API 面

- 状态：已接受（2026-11-11）

## 事实
- `librime-sys` 0.5.0：lotem（Rime 作者）维护，2026-11-07 更新，bindgen，默认动态链接 `-lrime`，支持 `LIBRIME_INCLUDE_DIR` / `LIBRIME_LIB_DIR`。
- `rime-api` 0.12.2：2024-09 后停更；`librime` 0.1.0：35 下载，不可依赖。

## 决策
用 `librime-sys` 作为 sys 层，在 `apps/desktop/src-tauri` 内写安全封装，只暴露：生命周期、session、输入处理、`get_commit/get_context/select_candidate`、config 读写、deployer、user_dict/sync。其余按需再提。

## 理由
GUI 用不到大部分 API；全量 wrapper 是纯维护负担。`rime-kit` 本身不依赖 FFI，保证 CI 在无 librime 的机器上也能跑单测。

## 后果
- FFI 代码只在 macOS/Windows 的构建 job 中编译；Linux CI 只跑纯 Rust 与前端。
