# ADR-0001 内核使用官方 librime，不 fork、不重写

- 状态：已接受（2026-11-11）
- 决策者：项目所有者

## 背景
需求是"Rime 支持的功能全都支持"。librime 是 BSD-3-Clause 的 C++17 引擎，提供稳定的 C ABI（`rime_api.h` / `rime_get_api()`），被 Squirrel、Weasel、ibus-rime、Trime 等前端使用。

## 决策
直接链接官方 librime 作为黑盒内核。不 fork 内核，不重写引擎。

## 备选与代价
- fork librime：只有在要改算法/引擎语义时才值得；本项目不需要，且会永久承担同步成本。
- 重写引擎：词典编译、方案解析、Lua 扩展、用户词典同步是数月级工作且永远追不上社区。

## 后果
- 上游升级即获得全部能力；风险集中在"配置层"而非"引擎层"。
- 许可证无传染（BSD-3），但外壳 fork 自带 GPL-3.0（见 ADR-0002）。
