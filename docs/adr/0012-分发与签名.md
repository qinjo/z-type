# ADR-0012 macOS 单 pkg 同装两件套并强制签名公证；Windows v1 不签名

- 状态：已接受（2026-11-11）

## 事实
- Squirrel 现用 `package/`（`pkgbuild` + `productbuild` 多 pkg-ref + `productsign` + `notarytool`），install-location 为 `/Library/Input Methods`，postinstall 做 `--register-input-source` 与预部署。
- macOS 26 上未签名或签名损坏的输入法一律被拦（adhoc 且无 quarantine 才勉强可用）；Apple Silicon 至少要求 adhoc 签名。

## 决策
- macOS：单个 pkg 同装 IME 与 GUI；Developer ID 签名 + 公证（购买开发者账号）。
- Windows：NSIS 单包同装 TSF DLL + WeaselServer + GUI；v1 不签名，接受 SmartScreen 提示。

## 后果
- 每年 99 美元成本；换机/重装时必须重新签名。
- 安装需要管理员权限，文档要写清。
