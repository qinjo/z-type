# ADR-0008 重载协议：复用官方入口，不新增 IPC 命令

- 状态：已接受（2026-11-11）

## 事实
- macOS：Squirrel 用 `NSDistributedNotificationCenter`，通知名 `SquirrelReloadNotification`；`Squirrel --reload` 负责投递，`--build` 走 `setup→deployer_initialize→deploy()`。
- Windows：`WeaselIPC` 命令枚举里没有 deploy/reload；官方部署路径是 `WeaselDeployer.exe /deploy`，内部 `StartMaintenance() → deploy() → deploy_config_file("weasel.yaml") → EndMaintenance()`。

## 决策
- macOS：spawn 外壳可执行文件 `--reload`（GUI 先自行 deploy）。
- Windows：GUI 自行校验性部署后，spawn `WeaselDeployer.exe /deploy` 做正式部署 + 重载。
- 两个都实现降级：失败时提示手动「重新部署」，并显示日志。

## 备选与代价
- 在 fork 的 WeaselIPC 增加 `DEPLOY` 命令：延迟更低，但协议一改，GUI 与外壳必须严格同版本，破坏灰度；仅在后续性能需要时再考虑。
- 直接重启输入法进程：会丢未上屏输入，不可单独使用。

## 后果
- Windows 端依赖 WeaselDeployer.exe 存在（属于 Weasel 安装的一部分）。
- macOS 的 reload 通道现成，Mac 端无需改外壳代码。
