# ADR-0005 文本级行编辑写回，配托管键清单与漂移检测

- 状态：已接受（2026-11-11）

## 背景
`parse → mutate → serialize` 会丢注释、重排键序、改写引号风格。Rime 用户的 YAML 里注释与顺序承载语义与可读性。

## 决策
1. 写回用**行级手术**：定位顶层 `patch:` 块，按 1 级缩进查找斜杠路径键，替换/插入/删除该键的行，其余行逐字节保留。
2. 用 `.rime-studio/state.json` 记录"GUI 拥有的键"及其上次写入值的 hash。
3. 写入前做漂移检测：文件里该键的当前值 hash ≠ 记录值 → 判定用户手改，默认不覆盖，进入冲突解决。
4. 幂等：同一批 edits 应用两次结果一致（golden test 断言）。

## 备选与代价
- 全量重写：实现简单、注释丢失，不可接受。
- 用 YAML AST + 保留注释的库（如 `yaml-rust2` 不保注释；`yamlpatch` 可行但生态弱）：仍无法保证任意手写文件的格式；行级手术更可控。

## 后果
- 需要覆盖完整的 golden 测试集（缩进、块序列、引号、空文件、无 patch 块、CRLF）。
- 对"用户把 patch 写成流式映射 `{}`"等极端形态，降级为只读并提示。
