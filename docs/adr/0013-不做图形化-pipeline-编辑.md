# ADR-0013 v1 不做图形化 schema pipeline 编辑

- 状态：已接受（2026-11-11）

## 背景
Rime 方案由 `processors / segmentors / translators / filters` 组成，图形化编辑听起来"完整"，实际没有稳定边界：字段由方案作者自由定义，插件可任意扩展。

## 决策
v1 不提供 pipeline 图形编辑器。改为：
- "高级"页直接打开原始 YAML（带语法高亮与校验错误定位）；
- "诊断"页把部署失败翻译成"哪个文件的哪个键"。

## 后果
- 省下最大的无底洞；把可视化预算集中在主题、键位、模糊音、双拼、标点、词典上。
