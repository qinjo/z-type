# ADR-0011 默认接管现有 Rime 用户目录，首启强引导 + 备份

- 状态：已接受（2026-11-11）

## 背景
用户（含项目所有者本人）通常已装好 rime-ice 等方案。新建独立目录会让用户"再下载一次方案、再配一次共享目录"。

## 决策
- 默认读取 `~/Library/Rime`（macOS）/ `%APPDATA%\Rime`（Windows）；支持多 profile（多个目录）。
- 首启流程：扫描现有目录并展示发现（方案列表、默认方案、共享目录位置）→ 自动打包备份 → 明确列出"我将修改哪些文件" → 用户确认后接管。
- 不做静默接管。

## 后果
- 需要健壮的备份/恢复（架构 §4.6）。
- 与用户已装的其他输入法（如仍保留 Squirrel）共享同一目录时，以 Rime 自身的多前端并存语义为准。
