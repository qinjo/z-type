# ADR-0006 统一主题模型，编译为两端原生配置

- 状态：已接受（2026-11-11）

## 背景
Squirrel 与 Weasel 的样式字段名与布局位置不同，但颜色编码一致（ABGR，`0xAABBGGRR`）。若按平台各做一套 UI，等于复刻 WeaselDeployer。

## 决策
- 单一 `Theme` 模型（字体 / 颜色 / 布局），颜色只存 RGBA，编译时统一 `to_abgr()`。
- 两个编译器：`compile_macos() → squirrel.custom.yaml`、`compile_windows() → weasel.custom.yaml`。
- 交集外字段进 `platform_specific`，UI 折叠区标注"仅某端生效"。

## 后果
- 同一份主题可跨端复用；新增字段只需改一处编译器。
- 上游改字段名会让主题静默失效 → 用契约测试（部署后读回 build）锁定。
