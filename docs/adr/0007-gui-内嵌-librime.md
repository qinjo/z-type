# ADR-0007 GUI 内嵌 librime 做校验、预览与部署

- 状态：已接受（2026-11-11）

## 决策
GUI 通过 `librime-sys`（Rime 作者维护，2026-11 更新）链接 librime，审计三点：
1. 保存前校验（方案引用是否存在、patch 是否合法）；
2. 保存后 `deployer_initialize() → deploy()`；
3. 预览：用临时 session 试打字，展示候选效果。

## 理由
"可视化"的价值在于改完立刻知道对不对。不内嵌就只能"写文件 → 让用户手动部署 → 自己看屏幕"，反馈环断开。

## 备选与代价
- 只写文件、部署交给外壳：实现最轻，但没有校验与预览，等于美化版文本编辑器。
- 只封装 `rime_deployer` 命令行：能做部署，但拿不到配置语义（校验/预览做不到）。

## 后果
- 需要随 GUI 分发 librime 及其依赖；双实例部署需锁（ADR-0008 / 架构 §6.3）。
- Rust 绑定只用最小 API 面（ADR-0010）。
