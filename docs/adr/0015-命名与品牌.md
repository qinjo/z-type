# ADR-0015 品牌命名：切韵 / Qieyun；仓库代号 z-type

- 状态：已接受（2026-11-11）
- 决策者：项目所有者

## 背景
仓库工作目录叫 `z-type`（内部代号）。产品名需要同时满足：可念、可搜、ASCII 可用、不与上游 Rime 名称混淆、不作为"描述性名称"导致商标不可注册。

## 候选与取舍

| 候选 | 优点 | 落选原因 |
|---|---|---|
| Rime Studio | 描述性最强 | 带 "Rime" 会被当成官方项目；描述性名称难注册 |
| 撇捺 / Piena | 亲切，直指书写 | 偏口语，工具感弱 |
| 句读 / Judou | 标点意象准确 | 语义偏窄 |
| 韵坊 / Yunfang | 贴合"配置工坊" | 输入法属性弱，像茶室 |
| 墨工 / Mogong | 工匠感强 | 与 Mojang 谐音、皮革品牌重名 |
| **切韵 / Qieyun** | 韵书之祖（601），与 Rime 的"中州韵"同源不同名；"切"暗合反切与切分 | 略文气（对 Rime 用户群是加分） |

## 决策
- 品牌：**切韵 / Qieyun**
- 输入法外壳：切韵输入法（Qieyun IME）
- 配置工作台：切韵工作台（Qieyun Studio）
- bundle id：`com.qieyun.ime` / `com.qieyun.studio`
- Rust 核心 crate：`qieyun-kit`；CLI：`qieyun`
- 仓库代号保持 `z-type`（历史路径），对外不出现

## 约束
1. **bundle id 发布后不可改**：影响输入源注册、更新链路与签名。若将来注册域名，ID 仍保持不变。
2. 名字里不出现 "Rime"，改在副标题声明引擎归属："基于 Rime 引擎"。
3. 公开分发前做一次软件类商标检索（"切韵"作为古籍名属公有领域，但需确认无同名软件商标）。

## 后果
- 所有显示名、bundle id、安装器文案、日志文件（`qieyun.log`）、状态目录（`.qieyun/`）统一使用该品牌。
- 改名成本在 M0 一次性付清；发布后不再改名。
