# ADR-0014 三层测试：golden / 契约 / 手工冒烟

- 状态：已接受（2026-11-11）

## 决策
1. **golden test**（纯 Rust，每台机器可跑）：写回幂等、注释与未托管键逐字节保留、序列/引号渲染、CRLF、空文件。
2. **契约测试**（CI macOS job，需 librime）：`qieyun-kit` 产出 → 内嵌 librime 部署 → 读回 `build/` 断言 patch 生效。这是唯一能证明"配置语义正确"的测试。
3. **手工冒烟清单**（每次发版）：输入、候选、翻页、中英切换、特殊符号、模糊音、双拼、主题、同步。

## 理由
GUI 测试证明不了配置语义；契约测试是成本/收益比最高的防线。端到端"驱动真实 IME 打字"成本过高，v1 不做。

## 后果
- CI 需要 macOS runner + 预编 librime；Windows job 至少编译通过。
